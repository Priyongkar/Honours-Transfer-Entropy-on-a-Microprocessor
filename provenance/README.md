# Code exactly as run

These are the analysis scripts, design files and shell runners byte-for-byte as they were run, with their
original names and folder layout (`analyses/new_tests`, `analyses/replication`, ...). The SHA-256 hashes
printed at the start of every run log refer to these files. The organised copies in `../analyses/` differ
only in imports, paths and names (`../docs/file_renames.md`).
